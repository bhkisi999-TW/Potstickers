# 一餃匠心｜訂單串接 Google 試算表

這份說明給網站擁有者，一步一步設定「結帳 → Google 試算表」。

## 運作方式
網站結帳 → Google Apps Script（網頁應用程式）→ 寫入你的 Google 試算表。

## 試算表分頁
- **訂單**：訂單編號、下單時間、姓名、電話、取餐方式、配送地址、商品件數、總金額、狀態（下拉選單）
- **訂單明細**：訂單編號、商品、單價、數量、小計
- **商品**：商品編號、名稱、價格、上架（勾選）。後端會用這張表的價格重新計算金額。

## 設定步驟
1. 到 Google 試算表建立一份**新的空白**試算表，命名例如「一餃匠心訂單（展示）」。
2. 選單：**擴充功能（Extensions）→ Apps Script**。
3. 把編輯器裡原本的程式全部刪除，貼上 `gas/Code.gs` 的全部內容，按**儲存（Save）**。
4. 上方函式下拉選單選 **setup**，按**執行（Run）**，依畫面完成**授權（Review permissions → Allow）**。
5. 回到試算表，應該會看到「訂單」「訂單明細」「商品」三個分頁。
6. （選用）函式選 **testOrder** 再執行一次，會新增一筆測試訂單，可手動刪除該列。
7. 右上角 **部署（Deploy）→ 新增部署作業（New deployment）**，類型選**網頁應用程式（Web app）**：
   - 執行身分（Execute as）：**我（Me）**
   - 誰可以存取（Who has access）：**所有人（Anyone）**
8. 按**部署（Deploy）**，複製**網頁應用程式網址**（結尾是 `/exec`）。
9. 把網址交給開發者，貼到網站 `index.html` 的 `ORDER_API_URL`。

## 之後修改程式
修改 Code.gs 後，要再次「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」，網址不會變。

## 安全提醒
- 網頁應用程式網址是公開的，任何人都能送資料進來；程式已做格式檢查、金額重算、防重複與每分鐘上限，但不是銀行等級的防護。
- 本專案為展示用途，請只用測試資料，不要放真實個資。
- 試算表本身不要設成「知道連結的人都能檢視」。
